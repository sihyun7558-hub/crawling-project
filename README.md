# MUSINSA Ranking Crawler

MUSINSAのランキングページから商品情報を取得し、画像・CSV・Excel形式で保存できるPythonデスクトップアプリケーションです。

ファッション・EC分野の商品トレンドを効率的に確認するため、ランキング情報の収集作業を自動化する目的で開発しました。

最初はPlaywrightを利用したシンプルなランキング取得ツールとして実装し、その後、実際に使用しながらGUI、画像保存、CSV・Excel出力、キーワード分析などの機能を段階的に追加しました。

---

## 主な機能

* MUSINSAランキングの商品情報を自動取得
* 取得するランキング範囲を指定
* TOP 10 / 20 / 50 / 100のクイック設定
* ブランド名・商品名・価格・順位の取得
* 商品画像の自動ダウンロード
* GUI上で取得した商品の画像を一覧表示
* CSV形式でデータを保存
* Excel（.xlsx）形式でデータを保存
* 商品名から頻出キーワードTOP 10を分析
* クロール進捗をプログレスバーで表示
* 実行中のクロール停止機能
* 保存先フォルダの指定

## 使用技術

| 技術            | 用途                  |
| ------------- | ------------------- |
| Python        | アプリケーション全体の実装       |
| Playwright    | 動的Webページの操作・商品情報取得  |
| CustomTkinter | デスクトップGUI           |
| Requests      | 商品画像の取得             |
| Pillow        | 画像処理・プレビュー          |
| OpenPyXL      | Excelファイルの生成        |

| threading     | GUIを停止させずにクロール処理を実行 |

        ↓
 ┌───────────────┬────────────────┐
 ↓               ↓                ↓
画像保存       CSV / Excel       GUI Gallery
                                   ↓

## GUI

URLを入力し、取得したいランキング範囲を設定して「抽出開始」を押すことでクロールを開始します。

取得した商品はGUI上のギャラリーに表示され、同時に進捗状況や取得結果を確認できます。

処理中に停止ボタンを押した場合でも、それまでに取得したデータを保存するように実装しています。

---

## キーワード分析

取得した商品の商品名を単語単位で抽出し、不要な単語を除外した上で出現回数を集計します。

```text
商品名
  ↓
正規表現による単語抽出
  ↓
STOP WORDS除外
  ↓
Counterによる出現回数集計
  ↓
頻出キーワード TOP 10
```

結果はGUI上に簡易バーグラフとして表示されます。

## データ出力

取得したデータは以下の形式で保存されます。

### CSV / Excel

| 順位 | ブランド  | 商品名          |    価格 | ファイル名     |
| -: | ----- | ------------ | ----: | --------- |
|  1 | BRAND | PRODUCT NAME | 10000 | image.jpg |

Excelファイルではヘッダーや列幅なども調整し、取得後すぐ確認しやすい形式にしています。

### 商品画像

商品画像は指定したフォルダに自動保存されます。

ファイル名には取得日・順位・ブランド・商品名・価格を含めています。

## インストール

### 1. リポジトリをクローン

```bash
git clone https://github.com/sihyun7558-hub/crawling-project.git
cd crawling-project
```

### 2. 必要なライブラリをインストール

```bash
pip install -r requirements.txt
```

### 3. Playwright Chromiumをインストール

```bash
playwright install chromium
```

---

## 実行方法

```bash
python crawler.py
```

起動後、

1. 保存先フォルダを選択
2. MUSINSAランキングページのURLを入力
3. 取得するランキング範囲を設定
4. 「抽出開始」をクリック

することでデータ取得を開始できます。
